## As regras da casa

1. Ninguém escreve directamente no `main` — tudo passa por um pull request.
2. Um pull request = uma mudança. Pequeno e com um título claro.
3. Antes de fazer merge, alguém do grupo revê.
4. O Claude escreve, vocês revêem.
